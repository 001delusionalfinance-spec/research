# Données calculées

Ce dossier est la **source unique** des sorties CSV produites par les modèles. Il n'en existe
pas de copie dans `recherche/`.

Pour une lecture rapide, partez du [rapport global](../lecture-du-jour.md) ou des
[rapports thématiques](../themes/). Chaque modèle y pointe vers son CSV. Le classeur
[`etat-recherche.xlsx`](../etat-recherche.xlsx) rassemble aussi toutes les tables dans un seul
fichier filtrable.
