# Graphiques utiles

Ce dossier ne contient pas un graphique par modèle. Une figure est conservée uniquement quand
elle rend une évolution temporelle ou une comparaison plus rapide à comprendre que le CSV.

Les sorties textuelles, contrôles, scores isolés et tableaux qui ne gagnent rien à être tracés
restent dans [`rapports/donnees/`](../donnees/). Les graphiques pertinents sont reliés depuis les
[rapports thématiques](../themes/).
